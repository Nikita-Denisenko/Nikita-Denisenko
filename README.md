## About Me

I work as a **Backend .NET Developer**, building backend systems with C# and .NET.

My main focus is backend engineering: designing APIs, structuring application logic, working with databases, implementing business rules and building maintainable application architecture.

I work with real projects where the backend is responsible for application logic, persistence, authentication, integrations and game-related systems.
